# ADR-0003 -- SLA (Formlabs Tough 2000) for the EVT housing and lid

Status: accepted, 2026-08-30. Decision: print EVT housings and lids by SLA in Tough 2000 for dimensional accuracy (+/-0.1 mm) and a smooth optical-window seat. Consequence: design to the SLA rules (min wall 0.5 mm supported / 1.0 mm unsupported); revisit for DVT (injection molding).
